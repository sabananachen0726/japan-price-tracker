批次匯入 Active／Inactive

 
貼上 Excel 兩欄 Item Code、Status，或直接上傳本系統匯出的「Active／Inactive Excel」。支援 .xlsx、.xls、.csv、.tsv。

 
 

 
Active＝可訂；Inactive＝暫停訂購（原本是「停產」的商品若仍設為 Inactive，會維持停產）。
未提供的商品不變；無法配對的品號不新增商品。__JAN_ 暫時編號若存在於清單也可更新，但未來配對正式品號後需重新確認狀態。TEST 模式只存本機；LIVE 才同步 Firebase。

 

 




 
批次匯入固定保存期限（月）

 
以 Barcode／JAN（優先） 或 Item Code 配對，支援從 Excel 貼上兩欄，或上傳 Excel／CSV。無標題兩欄會自動辨識第一欄的 Barcode／Item Code，第二欄為保存期限；可混合貼上。也支援 Barcode / JAN、Item Code 與 Shelf Life (Months) 標題。配對不唯一時略過並提示。月數限 1～120；空白略過，CLEAR 才清除既有值。

 
 
若同時提供 Barcode 和 Item Code，兩者必須指向同一商品；Barcode 重複對應多款商品或無法配對時，預覽會標示並略過。Excel 條碼欄請設為「文字」，保留開頭 0。

 

 
只套用已配對且實際變更的商品，預覽後才儲存；Admin／Editor 可修改，Viewer 唯讀。TEST 模式只儲存在本機。

 
 

 



更新 MYOB 庫存與 Factor
可直接貼上完整 MYOB 表格，讀取 Item Number、On Hand、Custom List 3。完整匯入後 MYOB Factor 優先；先前手動 Factor 自動失效。舊的兩欄格式仍可使用，但只更新庫存，不重設 Factor。
先預覽再確認。套用後會完整取代上一份庫存快照；未出現的品號庫存待確認。只更新庫存與 MYOB 單位，不修改商品主檔、價格、月銷或安全庫存。
