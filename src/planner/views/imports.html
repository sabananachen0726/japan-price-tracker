1. MYOB 庫存與 Factor 快照

完整 MYOB 貼上讀取 Item Number、On Hand、Custom List 3，以最新 MYOB 判定 Factor，清除舊手動覆蓋的效力；兩欄舊格式只更新庫存。先預覽後套用，不改商品主檔／價格／月銷／安全庫存。

2. 商品訂貨設定（建議使用）

一次匯入 月銷、安全庫存、Factor、保存期限、Active／Inactive。用 Item Code 配對，空白不修改，CLEAR 才清除數值。支援 Excel、CSV 或直接貼上；先預覽再套用。

只更新實際變動欄位；此功能不會新增商品、刪除 PI 或覆蓋 MYOB 庫存。

進階：只匯入單一設定／沿用舊 Excel 範本（點擊展開）

以下是原本的單獨匯入工具，繼續支援舊檔案。主要建議使用上方「合併商品設定」，避免分開匯入後互相覆蓋。

2. 月銷・安全庫存・Factor

三項共用同一份 Item Code 設定檔。已配對品號更新對應欄位，不會重設未提供的商品；若要清空數值請先確認預覽。

3. 固定保存期限（月）

單位為月，範圍 1～120；空白略過、CLEAR 才清除。與安全庫存同屬訂貨商品設定，但各自維護不同欄位。

固定保存期限（Shelf Life）可用 Barcode／JAN 或 Item Code 匯入；配對後依 Item Code 儲存月數。未填代表未設定，也可直接在訂貨列表修改。

4. Active／Inactive 訂貨狀態

控制商品是否出現在訂貨清單，不刪除商品主檔、PI 或工作單。支援使用系統匯出的狀態 Excel 重新匯入。

批次更新 Active／Inactive

可直接使用上方匯出的 Excel，或從 Excel 複製「Item Code + 狀態」貼上；先預覽，確認後才套用。

只更新已配對且狀態有變動的 Item Code；不會覆蓋商品名稱、庫存、安全庫存或 PI。

5. 客訂資料手動更新

客訂來自另一個 Firebase 專案。自動讀取使用瀏覽器 24 小時快取；必要時可按下面按鈕強制更新，最短間隔 30 秒。不是 Excel 匯入。

訂貨商品「查詢、匯出全部來源、匯出 Active／Inactive」仍放在「資料管理」，與資料輸入分開，避免誤將匯出當成匯入。
