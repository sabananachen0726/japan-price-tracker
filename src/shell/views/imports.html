① 商品主檔

直接匯入 Onsight Product Data Export Excel；按欄位名稱讀取，篩選 Place of Production Value 包含 JAPAN 的所有分類（不分大小寫）。依 Item Code 更新，同條碼商品全部保留並標註；未列出的舊商品不刪除。Admin 專用。

匯入 Onsight Product Data Export Excel（只取日本貨）：

讀取 Product Code、Barcode（空白改讀 Barcode Value）、Product Name、Image URL、Place of Production Value 及 Item Kind Value。不匯入庫存、價格或 Factor。

主檔匯入紀錄 / 復原
從此版本開始記錄最近 5 次匯入。可查看檔名與新增/更新筆數，並復原指定批次。舊版本已匯入的資料無法追溯到原始檔案。
尚無可復原的匯入紀錄。

② 廠商報價

同一組報價資料有三種輸入方式：大批 CSV／TXT、少量 Excel 貼上、單筆手動。匯入前請核對廠商、貨櫃與價格單位。

【快速】整批 CSV / TXT 報價單匯入

支援 Excel 匯出的 CSV 或 TXT 文字檔。若單價為 $0 可選擇或註明「停產」或「等待報價」。

快速補報價（適合廠商回覆十幾項等待報價）
不用做 CSV

先選廠商與貨櫃，再從 Excel 直接貼上多行。每行格式：Item Code / JAN、價格、備註（可空白）。支援 Tab、逗號或空白分隔。

貼上後會用 Item Code 或 JAN 自動找到商品；找不到的項目會建立為「待補商品資料」，報價仍會保留。
單筆手動錄入報價

PI 可加選填「保存期限（月）」／Shelf Life (Months) 欄位，填 1～120 整數。無標題時單櫃為第 6 欄、多櫃為第 8 欄；空白保留原設定。預覽會列出修改與衝突，確認後一併儲存。這是完整保存期限，不是剩餘效期。

③ Final PI

使用單櫃或多櫃匯入，都是同一套 PI 資料；同櫃再次匯入會完整覆蓋該櫃 PI 明細，並需重新核對 Final 標記。

Final PI 匯入 （點擊展開）

一條貨櫃只保留最後一份 Final PI；同櫃再次匯入會完整覆蓋舊明細。
價格＝單包價｜數量＝箱數
固定欄位順序：JAN Code / Barcode （必填）｜箱數 Qty(CTN) （必填）｜Item Code（選填）｜單包價 Unit Price（選填）｜Expiry Date（選填）｜保存期限（月）（選填）。選填欄位可留空；從 Excel 貼上時會保留中間空白欄位。
多櫃一次匯入
一份 CSV / Excel 貼上可包含多條貨櫃；系統依 Container No. 自動分組。已存在的貨櫃會以本次資料完整覆蓋，舊 PI 明細不合併。
多櫃固定順序：Container No.（必填）｜Supplier（必填）｜JAN Code（必填）｜Qty CTN（必填）｜Item Code（選填）｜Unit Price（選填）｜Expiry Date（選填）｜保存期限（月）（選填）。物流日期由 Container Tracker 管理。

④ 訂貨資料設定

Admin／Editor 可維護 MYOB 快照、月銷／安全庫存／Factor、保存期限與 Active／Inactive；客訂只手動更新，不另外匯入 Excel。

訂貨設定將顯示在下方。系統沿用同一個訂貨畫面與 Firebase 連線，不另開視窗或重複載入商品。

⑤ 備份／復原（高風險）

整份 JSON 備份還原不同於商品主檔匯入。只在必要時使用，先備份目前資料、檢查模式及確認可能覆蓋的範圍。

全系統資料備份與復原

包含商品主檔、圖片 URL、條碼綁定、廠商、報價歷史、待補商品狀態與主檔匯入復原紀錄。
