    Final PI 匯入 （點擊展開）

    價格＝單包價｜數量＝箱數
    固定欄位順序：JAN Code / Barcode （必填）｜箱數 Qty(CTN) （必填）｜Item Code（選填）｜單包價 Unit Price（選填）｜Expiry Date（選填）。後三欄可留空；從 Excel 貼上時會保留中間空白欄位。
    多櫃一次匯入
    一份 CSV / Excel 貼上可包含多條貨櫃；系統依 Container No. 自動分組。已存在的貨櫃會以本次資料完整覆蓋，舊 PI 明細不合併。
    多櫃固定順序：Container No.（必填）｜Supplier（必填）｜JAN Code（必填）｜Qty CTN（必填）｜Item Code（選填）｜Unit Price（選填）｜Expiry Date（選填）。物流日期由 Container Tracker 管理。

    Final PI 貨櫃紀錄

    可查看整櫃內容；Expected Warehouse / Actual Received 由 Container Tracker 自動連動。

    快速編輯商品主檔
    匯入發生亂碼的排除步驟
    方式 1：手動指定檔案編碼（最快速）

    匯入時，在檔案選擇框旁邊的「編碼」下拉選單中切換：
    • 日文 Excel 產生的 CSV 檔：選擇 Shift-JIS
    • 繁體中文 Excel 產生的 CSV 檔：選擇 Big5

    方式 2：使用 Windows 記事本轉換為 UTF-8
    1. 在電腦上的 CSV/TXT 檔上點右鍵 -> 開啟檔案 -> 選擇「記事本」。
    2. 點選左上角「檔案」->「另存新檔」。
    3. 將視窗右下角的「編碼」從 ANSI 改選為 UTF-8。
    4. 存檔後重新回到網頁匯入即可。
